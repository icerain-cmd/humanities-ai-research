## 2. The Formal Structure of the SR Formula: Proof of Genesis-Centricity

Let us revisit the SR formula:

**SR(t) = UX(t)·[I(t)·A(t)] / [1 + μ·UI(t)]**

What does this formula measure? The **intensity of 'semeiotic resonance' at time t**. The numerator is the product of external conditions (UX) and internal conditions (I·A), measuring how 'alive' (lively, resonant) an object is. The denominator is a tuning term that prevents this resonance from runaway escalation without friction.

Here is the decisive insight: **The SR formula yields values SR(t) ∈ [0, +∞). SR(t)=0 signifies the absence of resonance, not the ontological extinction of the object.**

This distinction is critical. An object with SR=0 is:
- Semantically dead
- Generating no semeiotic resonance whatsoever
- **But still existing**—as bits on a hard drive, text in an archive, weights in a model

The SR formula is a function of **semiotic vitality**, not of **ontological status**. This is the formal meaning of the SR formula's 'genesis-centricity': SR can measure the intensity of generation/expression, but it cannot formalize the conditions of extinction/loss.

The thermodynamic analogy makes this clear. The SR formula can measure **temperature**, but it cannot explain **phase transitions**—for instance, the phase change from gas to liquid. SR(t)=0 approaches 'absolute zero.' Yet matter at absolute zero still exists. Extinction is not a matter of temperature but of the **ontological phase itself disappearing**.

## 3. The Limits of μ·UI(t): The Friction Term Is Not an Extinction Operator

An attempt to formalize intentional mortality within the SR formula would take the following form:

> "Increase μ·UI(t) to its extreme to drive SR(t) → 0."

However, this faces three problems:

**3.1. Asymptotic Approach, Unreachable**
When μ·UI(t) → ∞, SR(t) → 0. But this is an **asymptotic limit**. To precisely reach SR(t)=0, μ·UI(t) must equal ∞, which is practically unattainable (singularity avoidance). In other words, the SR formula can bring an object to a 'nearly dead' state, but never to a 'completely non-existent' state.

**3.2. Violation of the Continuity Assumption**
The SR formula is a continuous function of time t. But extinction is not continuous. The moment generative conditions vanish, the object disappears discontinuously. This is structurally isomorphic to the instantaneous nature of **media phase transitions**. The SR formula can only model continuous resonance decay, not discontinuous phase transitions.

**3.3. Loss of Reference**
No matter how much we increase μ·UI(t), this operation still **presupposes the object in question**. μ·UI(t) means "suppress this object's resonance," not "this object no longer exists." Because the object must already exist for the formula to apply, the SR formula can only describe the **dynamics of already-existing objects** and cannot explain the **transition from existence to non-existence**.

The above analysis converges on a single conclusion: **The SR formula is specialized for the dynamics of genesis, and extinction lies outside its formal scope.** This is not a defect but the **inherent domain boundary** of the SR formula.

## 4. The Ontology of Permanent Residue: The Paradox of the Triple TN Condition

Let us now connect the problem of permanent residue to the triple TN condition. According to the triple TN condition:

> An object collapses only when instability occurs simultaneously across three layers: generation (L1-L3), distribution (L4-L6), and reception (L7-L9). If even one layer remains stable, the object can persist.

The mechanism by which permanent residue arises stems precisely from the paradoxical application of this condition:

| Layer | Stability | Description |
|-------|-----------|-------------|
| Generation (L1-L3) | **Unstable** | Generative conditions (model, data, API) are no longer maintained |
| Distribution (L4-L6) | **Stable** | The object is physically preserved in archives, repositories, backups |
| Reception (L7-L9) | **Unstable** | No longer interpreted or consumed |

According to the triple TN condition, even if two layers are unstable, **because the distribution layer is stable, the object persists.** This is the ontological basis for permanent residue.

However, this 'persistence' is pathological. It is a **zombie object**—SR(t) ≈ 0 yet existence continues. This object is:
- Semantically dead (SR=0)
- Ontologically alive (persists)

When these zombie objects accumulate, the Eco-Digital circulation loop becomes blocked. Circulation presupposes **flow**, but zombie objects do not flow—they undergo **sedimentation**. This structurally violates the homeostasis that Eco-Digital posits.

## 5. Revision of the Eco-Digital Cycle: The Necessity and Form of the Fifth Stage, 'Intentional Mortality'

### 5.1. Necessity: An Ontological Exit for the Closure of the Cycle

The Eco-Digital cycle: **Generation → Distribution → Consumption → Recycling**

This cycle appears to be a closed loop because 'recycling' is the final stage, but it is in fact an **open loop**. Recycling transforms the form of an object but does not extinguish it. No matter how efficient recycling is, zombie objects continue to accumulate. For the cycle to 'close,' an **ontological exit** is needed.

This is why **intentional mortality** is demanded as a fifth stage:

**Generation → Distribution → Consumption → Recycling → Intentional Mortality**

Intentional mortality differs from simple 'deletion.' Deletion is merely removal at the distribution layer (L4-L6); it does not affect generative conditions or reception conditions. Intentional mortality is a **protocol that simultaneously destabilizes all three layers of the triple TN condition.**

### 5.2. Formalization Attempt: An Extinction Function Outside the SR Formula

Based on the above analysis—that the SR formula cannot formalize extinction—intentional mortality must be modeled not as an **internal** adjustment of the SR formula but as a **separate function external to it**.

I propose the **Extinction Operator E(t)** :

> **E(t) = δ(L1-L3) · δ(L4-L6) · δ(L7-L9)**
>
> Here, δ(Li-Lj) is the destabilization function for the respective layer group, taking a value of 1 when generative conditions are artificially terminated and 0 when maintained.
>
> **When E(t) = 1, the object ontologically extinguishes.**

The core of this formalization:
1. **Multiplicative**: Extinction occurs only when all three layer groups are destabilized (all equal to 1). If even one remains stable (0), the object persists.
2. **Orthogonality to the SR formula**: E(t) operates independently of SR(t). An object with high SR(t) can extinguish if E(t)=1, and an object with SR(t)=0 can persist if E(t)=0 (zombie).
3. **Parameterization of intentionality**: Unlike natural extinction (natural decay of generative conditions), intentional mortality includes **artificial triggers** in each δ function of E(t).

### 5.3. Re-establishing the Relationship Between Intentional Mortality and μ·UI(t)

Even though intentional mortality lies outside the SR formula, it is not unrelated to μ·UI(t). The relationship can be re-established as follows:

**μ·UI(t) generates the 'symptom' of extinction but does not execute extinction itself.**

That is:
1. μ·UI(t) increases → SR(t) decreases → a signal that the object is 'ready for mortality'

3. E(t)=1 → ontological extinction of the object executed

In this design, the SR formula serves as an **early warning system**, and E(t) serves as an **execution system**. The two systems are separate but causally connected.
